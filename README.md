# Escriu

## English

This is Escriu. It is a lightweight text processor that partially supports Markdown. It allows minimal text editing, offering a clean presentation without being highly complex, so most editors can support it.

The application, which provides visual editing of Markdown formatting, includes the minimum essentials needed to work with files using open, save, and save as new file options.

### Objectives

The idea behind this project was to meet a personal need: to have a minimalist, lightweight, and fast text editor, while also exploring how text processors are created.

### Implementation

The application has been implemented with JavaScript and Electron, with the help of a ChatGPT agent. Efforts were made to keep npm package usage to a minimum to avoid increasing the application's size.

### Extras

A word and character counter has been added, as well as an estimated reading time, assuming a reading speed of 200 words per minute.

## Catalá

Això és Escriu. Es tracta d'un processador de textos lleugers que suporta, parcialment, el llenguatge Markdown. Aquest permet un minim d'edició del text, oferint una presentació neta a la vegada que no altament complexa, pel que la majoria d'editors el poden suportar.

L'aplicació, que ofereix l'edició de forma visual del format Markdown, presenta els mínims necessaris per a poder treballar amb fitxers mitjançant les opcions d'obrir, desar i desar com a nou fitxer.

### Objectius

L'idea d'aquest projecte era satisfer una necessitat pròpia com és la de tenir un editor de text minimalista, lleuger i ràpid, a la vegada que explorar la forma en que es creen els processadors de text.

### Implementació

L'aplicació ha estat implementada amb Javascript i Electron, amb l'ajuda d'un agent de ChatGPT. S'ha intentat mantenir sota minims l'ús de paquets de npm, per evitar incrementar el pes de l'aplicació.

### Extres

S'ha afegit un comptador de paraules i caràcters, així com una estimació de l'estona de lectura, assumint una velocitat de lectura de 200 paraules per minut.
